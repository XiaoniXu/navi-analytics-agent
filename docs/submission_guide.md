# Submission and Portfolio Guide

## A review-ready project

Your project will be easy to review when another person can clone or unzip it, follow the README, rebuild the warehouse, launch Streamlit, and understand what the Analytics Agent is doing.

## Helpful materials to include

- Source code for ETL, dashboard, and Agent tools
- A short data-quality note with key decisions and validation checks
- A README with setup and run instructions
- A SQLite database or a clear rebuild process
- Dashboard screenshots or a short screen recording
- A concise business memo with 3 to 5 insights and practical next steps

## Portfolio framing

A concise project description could look like this:

> Built a Python and SQL analytics pipeline for a mobile AI study app, modeled product and agent-interaction data in SQLite, and developed a Streamlit dashboard with a tool-using LLM Analytics Agent for grounded KPI questions about DAU, agent quality, retention, and subscription conversion.

## Suggested business memo outline

1. Product goal and data scope
2. Data-quality and metric decisions
3. Key engagement, agent-health, and subscription findings
4. Recommended product actions and monitoring plan
5. Limitations and follow-up questions
